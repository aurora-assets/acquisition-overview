Composite Role Formation Rule

1. Preconditions
For a composite role to form, Genesis checks:
(a) Multi-agent requirement
The action cannot be accomplished by one agent alone.
(e.g., hunting large prey, carrying something heavy, cooperative defense, planning migration)
(b) Shared intention
At least two agents align on a goal.
(Explicit or implicit — gesture, stance, tone, etc.)
(c) Mutual recognition
Agents signal willingness or acceptance.
(A nod, approach, readiness posture, shared gaze — prehistoric or modern, same mechanic.)
These three are enough to initiate “we.”

2. Formation Rule
Once conditions (a)–(c) are met:
A Composite Role is instantiated:
CR = {A + B + ...}
This is the operational birth of “we.”
Not a word.
A structure.

3. Domain Activation
Composite Role formation automatically triggers a domain transition.
The system chooses the domain based on the governing action (verb-intent):
“go” → Movement Domain
“hunt” → Task Domain
“watch” → Perception Domain
“plan” → Intention Domain
“warn” → Threat Domain
“share” → Resource Domain
“talk” → Conversation Domain
Primitive languages, gesture-based communication, and fully grammatical languages all use the same structure.
This is the deep machinery of meaning.

4. Agency Distribution
Inside the active domain, roles distribute automatically:
leader / follower
driver / flanker
hunter / supporter
speaker / listener
planner / executor
Not grammar.
Not culture.
It’s built into the physics of cooperation.
Genesis formalizes it cleanly:
Composite Roles contain subroles that evolve with context.
This is why “we” never means equal participants —
it means aligned participants.

5. Domain Span (Lifetime)
Composite Role persists until one of the following ends the domain:
goal achieved
threat neutralized
resource secured
movement completed
conversation closed
intention abandoned
Then Genesis executes:
CR → dissolve()
and agents return to individual roles.
“We” ends because the action ends.

6. Universal Invariant
This is the hard, mathematical guardrail:
No composite role can exist without an active domain.
No domain requiring multiple roles can function without a composite role.
They co-create each other.
This is the engine of multi-agent meaning.

7. Summary (the crisp version engineers love)
If (multi-agent action) AND (shared intention) AND (mutual recognition):
 → Instantiate Composite Role (“we”)
 → Activate Domain(type = verb-intent)
 → Allocate Subroles inside domain
 → Persist until domain terminates
 → Dissolve composite role
That’s a runnable specification.

8. Why this matters
Because this is the single rule that allows Genesis to handle:
pre-linguistic cooperation
hunter-gatherer communication
modern group actions
conversational planning
joint decision-making
negotiation
coordination
social bonding
responsibility
obligation
shared memory
…with one elegant structural law.
